# fishtrophic 0.1.0

## First look at low-trophic fish in FishBase

* **NEW** Native freshwater and brackish-water fish for any set of countries can be pulled from FishBase, with their trophic level, feeding type, growth, nutrient content and whether they are farmed.
* **NEW** Each species gets a nutritional score from 0 to 1: protein counts for 40%, and iron, zinc, calcium, vitamin A and omega-3 for 12% each.
* **NEW** Each species gets a growth-yield score, which combines how fast it grows with how heavy it can get.
* **NEW** A chart compares trophic level with growth-yield, with point size showing the nutritional score and colour showing whether the species is farmed.
* **NEW** An analysis notebook shows each step with its code and the chart, and can be shared as a single web page.
